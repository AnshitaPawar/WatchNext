# WatchNext -: Movie-Recommendation-System-Using-Python
WatchNext is a movie recommendation system made with Python and pandas. It looks at details like movie actors, and directors to suggest other movies similar to the one you like.

## FEATURES
- Content-based filtering using movie metadata

- Recommends similar movies based on title input

- Uses cosine similarity for finding recommendations

- Clean, beginner-friendly Jupyter Notebook code

## TECHNOLOGY
- Python

- Pandas

- Scikit-learn

- Jupyter Notebook

## INSTALLATION
1. Clone the repository: git clone https://github.com/AnshitaPawar/WatchNext.git

   cd WatchNext
   
2. Install required packages: pip install -r requirements.txt
   
3. Launch the Jupyter Notebook: jupyter notebook Movie-Recommendation-System.ipynb

## HOW TO USE
1. Open the notebook and run all cells.

2. In the input cell, enter the name of a movie you like (e.g., The Dark Knight).

3. The system will recommend a list of similar movies.
